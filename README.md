и собственного удобства.

Ввиду ограниченного времени (не хотел оставлять всё на выходные) я не смог разобраться в библиотеке с:

1. ШИМ сигналом для управления звонилкой. Сделал обычное управление пином, чтобы было что-то.
2. Задержками, т.к. до этого всегда пользовался vTaskDelay в FreeRTOS или стандартным HAL_Delay в некоторых случаях.
